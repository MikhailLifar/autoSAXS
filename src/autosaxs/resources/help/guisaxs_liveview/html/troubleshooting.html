Troubleshooting

Skill failed

Check WorkingDir/runs/latest/stderr.log and result.yml (also the Logs → Full tab). The UI shows a dialog for calibration and analysis skill failures.

Cannot change watchdir or watch mode

Wait until the queue is Idle (no skill running). Changing the working directory restarts the app (same idea as after Update); the new process cold-starts in the chosen folder.

Plots empty when browsing history

That TIFF may not have been processed with the current calibration/buffer/analysis settings. Use Process to re-run the pipeline. See Concepts (session history).

Update failed

Ensure network access to the git server and write permission to the Python environment. Editable installs may need a manual git pull and reinstall.

Help missing or empty

Reinstall autosaxs[gui] or verify that autosaxs/resources/help/guisaxs_liveview/ is present in your installation (manifest.yaml, html/, style/). Clear ~/.cache/autosaxs/help/guisaxs_liveview/ if an old cached copy is stuck.
