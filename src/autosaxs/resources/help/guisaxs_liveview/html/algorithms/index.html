Algorithms

These pages describe what autosaxs does scientifically when liveview runs a processing step — aimed at users with a SAXS / physics background. Each page covers purpose (why the step exists) and the custom autosaxs procedure (what is not a plain ATSAS or pyFAI default).

For where to click in the GUI, use the window pages (Main, Calibration, analysis). For how the app organizes work, see Concepts.

From image to I(q)

  • Detector calibration — ring-based geometry (custom) + pyFAI refine
  • Uncalibrated quick-look — pixel-space radial average
  • Azimuthal integration — calibrated I(q) via pyFAI
  • Buffer subtraction — point-match scaling (custom)

Low-q and real space

  • Guinier analysis — adaptive interval selection (custom)
  • Pair-distance distribution p(r) — DATGNOM + autosaxs search / QC
  • Size distribution D(R) — GNOM spheres + autosaxs search / QC
  • Parametric sphere mixture — MIXTURE grid + BIC selection

Shape and density

  • Geometric bodies — ATSAS BODIES + autosaxs orchestration
  • Ab initio bead model (DAM) — DAMMIF / DAMAVER orchestration
  • Continuous density (DENSS) — Grant-style protocol + σ map
