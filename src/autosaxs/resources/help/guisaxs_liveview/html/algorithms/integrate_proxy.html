Uncalibrated quick-look

Purpose. Before geometry is known, you may still want a 1D intensity curve to see whether a frame looks sane (beam on sample, strong scatterer, empty beam). This is a diagnostic curve, not a q-calibrated profile for Guinier or GNOM.

What autosaxs does (custom). The skill radially averages the TIFF in pixel-radius space. If the beam center is not supplied, it estimates the center by optimizing radial symmetry of the image (and can write a center diagnostic plot). Masked pixels are excluded when a mask is provided.

In liveview. Until Set calibration succeeds, new TIFFs use this path; outputs go under averaged_proxy/. After calibration, frames use true azimuthal integration instead.

Limitation. Do not interpret Rg, Dmax, or absolute q from proxy curves.

Engines. Custom center estimate + radial binning (not pyFAI geometry).
