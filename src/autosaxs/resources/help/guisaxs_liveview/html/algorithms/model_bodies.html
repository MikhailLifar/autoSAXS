Geometric bodies

Purpose. If the particle is expected to resemble a simple solid (ellipsoid, cylinder, …), fitting analytical form factors is faster and more interpretable than free ab initio shapes. Comparing several body types ranks which primitive best matches I(q).

Engine. ATSAS bodies. Autosaxs orchestrates which shapes to run and how results are exported for liveview.

What autosaxs adds.

  1. Optionally runs a subset of body models (or all bundled defaults).
  2. Sets --first from the Guinier interval when you do not override it, so the fit starts where the low-q region is trusted.
  3. Ranks fits and builds visualization aids, including a Monte Carlo p(r)-style view from voxelized body shapes for the 3D pane.

This is mostly ATSAS science; the custom layer is selection, Guinier coupling, and presentation.
