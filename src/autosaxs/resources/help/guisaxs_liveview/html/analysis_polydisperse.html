Polydisperse analysis

Open this window from the right-column polydisperse icon. While it stays open, new samples run Guinier → fit_sizes (D(R)) automatically. Closing the window disarms that chain. Guinier here is independent of the monodisperse window and is stored under guinier_poly/.

Each analysis pane shows plots, a Passport table, and Adjust (controls live in wizards). Optional MIXTURE modeling is launched with Start modeling into a separate Distribution Modeling app — press Confirm there to run.

Polydisperse Guinier quality is often poor; that is expected and does not feed fit_sizes as a hard constraint. Parameter edits (and confirming an Adjust wizard) pause auto-processing until you Resume auto-processing (Ctrl+P; Ctrl+X stops auto).

Layout

  • Guinier — independent display / passport / Adjust (same style as monodisperse Guinier).
  • GNOM D(R) — I(q) and D(R) plots, quality Passport, and Adjust (opens the D(R) / GNOM wizard).
  • D(R) mixture pane — None / MIXTURE; Start modeling; I(q) / Distribution previews after a MIXTURE run. (Older “Re-run D(R)” remains available for a sizes-only re-fit of the current profile.)
  • Global — Stop auto-processing / Resume auto-processing (Ctrl+X / Ctrl+P).

Recipes

To arm polydisperse analysis

Main window right → polydisperse icon → window opens (armed while open).

To adjust Guinier (poly)

Click Adjust under the Guinier passport → edit first/last → Confirm. This does not pin fit_sizes; it only refreshes the poly Guinier display / guinier_poly/ artifacts.

To adjust D(R) / fit_sizes

Click Adjust (or either embedded GNOM plot) → edit q-range / rmin / rmax / alpha and boundary checkboxes in the wizard. Plots and passport update live; press Confirm to write parameters and re-run fit_sizes (pinned Rmax refine). Opening the wizard alone does not pause the queue — the first control change does. Use Restore auto to return to the last auto-fit snapshot. Click a wizard plot to open an enlarged viewer (matplotlib toolbar + title-bar maximize). Then Resume auto-processing when ready.

To enable MIXTURE

Under the mixture pane, choose MIXTURE (vs None) → Start modeling → Distribution Modeling app opens → Confirm there to run model_mixture. When that app is open and auto is on, finishing D(R) can prompt Confirm on the modeling app.

To browse MIXTURE results (advanced viewer)

In the Distribution Modeling app, after a successful MIXTURE run, click the Distribution plot to open the advanced MIXTURE viewer (model combo, mixture + component previews, BIC_χ²). Left-column component thumbnails select the large view only (they do not open a separate window). Click the large plot to enlarge further (title-bar maximize).

To pause or resume the auto chain

Stop auto-processing (Ctrl+X) → Resume auto-processing (Ctrl+P) when ready.

Outputs (per sample)

  • guinier_poly/<stem>/ — Guinier region YAML
  • fit_sizes/<stem>/ — GNOM .out, D(R) CSV, quality YAML
  • mixture/<stem>/ — per-model dirs, mixture_results.csv (when MIXTURE has run)
