guisaxs-liveview

guisaxs-liveview watches a folder for new SAXS .tif / .tiff images, queues them, and processes them through calibration, integration, optional buffer subtraction, and optional monodisperse / polydisperse analysis.

Start with the Main window page for the session workflow, layouts, and step-by-step recipes. For a physicist-oriented mental model (working directory, queue, auto vs manual, TIFF revision, …), see Concepts. For what each processing step does scientifically, see Algorithms.
