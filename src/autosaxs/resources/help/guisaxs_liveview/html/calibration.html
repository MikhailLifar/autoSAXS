Calibration

The Calibrate wizard builds (or refreshes) the pyFAI integrator for the current working directory. You point it at a calibrant TIFF and optional mask; Run writes results under WorkingDir/calibration/ (including integrator/ and refined.yml). Until calibration succeeds, new TIFFs are integrated only in a coarse proxy mode.

Mask is optional: leave the mask path empty to use the automatic mask. Edit masks in the shared Mask wizard (Configure mask here, or left-column Set mask). After a successful run, the right side shows a geometry results table (sample–detector distance, beam center, rotations, wavelength).

Layout

  • Left — calibrant image viewer (drop a TIFF onto the canvas, or set calibrant_image). Click the image (when not zooming/panning) to open the mask wizard on this frame.
  • Right — skill form (Inputs / options): calibrant, wavelength, optional mask path; geometry results table after a successful run.
  • Top-right — Configure mask.
  • Bottom — Run / status, Reset, Close.

Recipes

To open the wizard

Main window left → Calibrate.

To create or edit a mask

Configure mask → Mask wizard opens → edit / Save mask → return here (mask path updates). Full steps: Mask.

To run calibration

Set calibrant_image (TIFF) → optionally set mask (or leave empty for auto-mask) → Run → wait until the wizard status is Idle → check the results table → Close.

To clear calibration

Left panel Reset (Calibration group), or Reset inside the wizard — clears session calibration and returns toward uncalibrated proxy integration.
