Calibration

The Calibrate wizard builds (or refreshes) the pyFAI integrator for the current working directory. You point it at a calibrant TIFF and optional mask; Run writes results under WorkingDir/calibration/ (including integrator/ and refined.yml). Until calibration succeeds, new TIFFs are integrated only in a coarse proxy mode.

Mask is optional: leave the mask path empty to use the automatic mask. Edit masks in the shared Mask wizard (View/Configure mask here, or left-column Set mask).

Layout

  • Left — calibrant image viewer (drop a TIFF onto Drop .tif).
  • Right — skill form (Inputs / Options), including mask path and calibrant options; View/Configure mask above the form.
  • Bottom — Run / status, Reset, Close.

Recipes

To open the wizard

Main window left → Calibrate.

To create or edit a mask

View/Configure mask → Mask wizard opens → edit / Save mask → return here (mask path updates). Full steps: Mask.

To run calibration

Set calibrant_image (TIFF) → optionally set mask (or leave empty for auto-mask) → Run → wait until the wizard status is Idle → Close.

To clear calibration

Left panel Reset (Calibration group), or Reset inside the wizard — clears session calibration and returns toward uncalibrated proxy integration.
