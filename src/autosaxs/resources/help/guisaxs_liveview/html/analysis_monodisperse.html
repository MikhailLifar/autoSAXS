Monodisperse analysis

Open this window from the right-column monodisperse icon. While it stays open, new TIFFs that reach a calibrated (and optionally subtracted) 1D profile run Guinier → P(r) / GNOM automatically. Closing the window disarms that chain. Optional shape modeling (BODIES / DAMMIF / DENSS) is launched with Start modeling into a separate Shape Modeling app — press Confirm there to run.

Manual edits in Guinier or confirming the P(r) Adjust wizard pause auto-processing until you Resume auto-processing (shortcut Ctrl+P; Ctrl+X stops auto). Guinier artifacts for this window live under guinier_mono/ (separate from polydisperse).

Layout

  • Guinier — plot; Quality / Classification / Rg; first / last (auto allowed).
  • P(r) — embedded I(q) and P(r) plots; quality passport; Adjust opens the GNOM wizard (or click either plot). Controls live only in that wizard.
  • Shape — None / BODIES / DAMMIF / DENSS; Start modeling opens the Shape Modeling app; I(q) fit and 3D preview; Open model folder… when artifacts exist.
  • Global — Stop auto-processing / Resume auto-processing (Ctrl+X / Ctrl+P).

Recipes

To arm monodisperse analysis

Main window right → monodisperse icon → window opens (armed while open).

To change Guinier limits

Edit first / last → auto-processing pauses → Guinier then GNOM re-run for the current profile → Resume auto-processing when ready for new files.

To adjust P(r) / GNOM

Click Adjust (or the embedded P(r) / I(q) plots) → dedicated wizard with P(r), I(q) fit, first/last, Dmax, alpha, boundary checkboxes, and passport. Plots and passport update live as you edit; press Confirm to write parameters and re-run fit_distances. Use Restore auto to return to the auto-fit Dmax/alpha snapshot. Click a wizard plot to open an enlarged viewer (matplotlib toolbar + title-bar maximize). Resume auto-processing when ready; re-run shape modeling if needed.

To enable shape modeling

Under Shape, choose BODIES, DAMMIF, or DENSS (and options as needed) → Start modeling → Shape Modeling app opens → set run knobs → Confirm there. When the Shape Modeling app is open and auto is on, new profiles that finish GNOM can prompt Confirm on that app. Use Open model folder… for on-disk 3D outputs.

To pause or resume the auto chain

Stop auto-processing (Ctrl+X) → new files skip analysis until Resume auto-processing (Ctrl+P).

Outputs (per TIFF)

  • guinier_mono/<stem>/ — Guinier region / quality
  • fit_distances/<stem>/ — GNOM .out, p(r) / fit plots
  • model_bodies/, dammif/, or denss/ under the stem when shape modeling has run
