Quick start

  1. Activate a Python environment with autosaxs[gui] installed.
  2. Run guisaxs-liveview from the folder you want as working directory (or later: File → Open working directory…).
  3. Follow the Main window workflow for frames: intake 2D → calibrate → [integrate buffer] → [set buffer] → integrate samples → [subtract] → [analysis], or set Intake to 1D/Sub and drop curves. Exact control sequences and screenshots: Main window.
  4. Calibration details: Calibration · Mask.
  5. Optional analysis: Monodisperse · Polydisperse.
  6. Mental model: Concepts. Algorithms: Algorithms.
